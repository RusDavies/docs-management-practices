## Usage Notes

- Use one coordination path so audit response does not become a scavenger hunt with deadlines.
- Track evidence links, not only “sent” status. Future-you deserves mercy.
- After the review, fix the evidence system instead of celebrating that the archaeology expedition survived.

## Example

A SOC 2 audit tracker might include access-review evidence, incident-response records, vendor-review samples, change-management tickets, vulnerability remediation evidence, management responses, and post-audit remediation actions.
