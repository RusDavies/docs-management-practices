# Operating Cadence Map

## Purpose

Map the team’s recurring meetings, reviews, rituals, updates, and decision forums so each one has a purpose, owner, input, output, and reason to exist.

## Usage Notes

- Every recurring forum should coordinate, decide, learn, improve, or communicate. “Because calendar” is not a management theory.
- Stop or redesign rituals that no longer produce useful outputs.
- Use async updates where they work; use live discussion where ambiguity, conflict, or tradeoffs need real conversation.

## Example

A support team might use daily queue review, weekly escalation themes, monthly customer-health input, and quarterly process improvement review, each with clear outputs and owners.
