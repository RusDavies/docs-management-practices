## Usage Notes

- Use when delegation needs clearer boundaries than a casual task assignment.
- Pick the delegation level explicitly.
- Define escalation conditions so the delegate is not punished for using judgment.
- Review and adjust as capability, risk, and trust change.

## Example

Delegate onboarding-process improvement to a team lead: they can gather evidence, propose changes, decide minor documentation updates, but need manager approval for tool purchases or policy changes.
