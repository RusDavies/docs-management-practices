## Usage Notes

- “Mitigate” is not an action. Name the work, owner, date, and evidence.
- Define contingency triggers before the risk materializes; crisis is a poor time for creative governance theatre.
- Use this for material risks where one row in a register is not enough.

## Example

For a supplier integration delay, mitigation might include weekly milestone reviews and fallback design work. Contingency might defer non-critical launch scope or run a manual operational workaround for the first customer cohort.
