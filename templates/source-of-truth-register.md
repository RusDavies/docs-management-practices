## Usage Notes

- Use when multiple sources answer the same question differently.
- Pair with the content ownership register and stale-content review list.
- Make the winning source easy to find. If the answer exists only after a treasure hunt, congratulations, you have built folklore with folders.

## Example

For pricing exceptions, the source of truth may be the approved commercial policy, not old Slack threads, sales deck screenshots, or “what we did for that one customer in March.”
