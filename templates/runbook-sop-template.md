## Usage Notes

- Test runbooks under realistic conditions. A procedure that only works when the expert is calm, available, and caffeinated is not quite a procedure.
- Include validation and failure handling, not just happy-path steps.
- Update after incidents, support escalations, tooling changes, access changes, or repeated confusion.

## Example

A data-refresh SOP might include prerequisites, access checks, scheduled window, commands or UI steps, validation queries, reconciliation evidence, rollback path, support contacts, and what to do if the source file is malformed.
