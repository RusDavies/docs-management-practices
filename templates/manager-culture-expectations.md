## Calibration Questions

- Which manager behaviours are consistently strong?
- Which manager behaviours vary too much by team?
- Which expectations are unclear or unsupported?
- Where are high performers allowed to violate expectations?
- Where are managers carrying cultural work without enough authority or training?

## Usage Notes

- Use alongside performance expectations, not as a vague “leadership style” note.
- Calibrate expectations across manager levels so culture does not depend on local folklore.
- Treat repeated failure to address harmful behaviour as a management performance issue.

## Example

If a manager consistently avoids conflict, the expectation is not “be braver.” The expectation is to name the issue, set a behaviour standard, document the follow-up, and escalate if the behaviour repeats.
